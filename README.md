
# 📊 Sales Analytics Dashboard

A sales analytics dashboard built using Python and Streamlit.

## 🚀 Project Overview

This project analyzes sales data and displays useful business insights through an interactive dashboard.

## 🛠️ Technologies Used

- Python
- Pandas
- Streamlit
- Matplotlib

## 📊 Dashboard Features

- Total sales KPI
- Total quantity KPI
- Product count
- Category-wise sales chart
- Product-wise sales chart
- Sales sequence chart
- Category filter
- Business insights
- CSV download

## ▶️ How to Run

1. Clone or download this project.
2. Open the project folder.
3. Activate the virtual environment.
4. Run the following command:

```bash
streamlit run dashboard.py
```
